# Spotify Clone

A frontend clone of Spotify's web player, built while following [Code With Harry's Sigma Web Development course](https://www.youtube.com/@CodeWithHarry). This project is for learning purposes — recreating Spotify's UI and layout using vanilla HTML, CSS, and JavaScript.

## Status: In Progress

This is an active learning project. Features and structure are being added incrementally as I progress through the course.

## Built so far

- Sidebar layout with Spotify logo
- Navigation section (Home, Search)
- "Your Library" section
- Footer with legal links (Legal, Safety & Privacy, Privacy Policy, Cookies, About Ads, Accessibility)

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Getting started

1. Clone the repo:
   ```bash
   git clone https://github.com/ShaunGeorge188/spotify-clone.git
   ```
2. Open `index.html` in your browser, or serve it locally (e.g. with VS Code's Live Server extension).
